# Projeto Integrador - 2ª Etapa: Sistema de Agendamento para Trabalhadores Autônomos
**Curso:** Análise e Desenvolvimento de Sistemas / Tecnologia da Informação (Senac EAD)

## 📌 Sobre o Projeto
Este projeto consiste no desenvolvimento de um aplicativo voltado para trabalhadores autônomos, facilitando a organização de horários e permitindo que clientes marquem serviços de forma rápida e intuitiva.

## 🎯 Prova de Conceito (PoC) Implementada
Nesta 2ª etapa, o foco foi a **jornada principal de agendamento**:
- O cliente consegue visualizar horários disponíveis, selecionar um serviço e realizar o agendamento, registrando os dados no sistema.

## 🛠️ Tecnologias Utilizadas
- **Frontend (Interface):** HMTL e CSS
- **Backend (Servidor/Lógica):** A definir
- **Banco de Dados:** A definir
- **Ferramentas de apoio:** Git, GitHub, Visual Studio Code
